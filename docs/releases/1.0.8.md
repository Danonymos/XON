# XON Shader 1.0.8 — Golden light, cooler shade

Pale golden sunlight, teal-blue shade and deeper blue nights give XON a richer,
slightly quieter atmosphere. The existing brightness control keeps its default;
the base exposure and color palette do the balancing.

## Improved

- Gentler base exposure, restrained saturation and more nuanced time-of-day colors.
- Moon glints now respect shadow casters, including water beneath cover.
- Fine block-surface relief follows the active sun or moon, fixing night highlights.
- Foliage avoids lighting calculations whose contributions are already zero.
  Existing shadow filtering, texture lookup limits and render passes remain.
- Retain built-in AA, soft colored ore auras, evolving cloud shade and moonlit gaps.

## Install

Place **XON-Shader-v1.0.8.zip** in your Minecraft instance's `shaderpacks` folder,
then select it in Iris and Apply. Start with Balanced + Native. Install the runtime
ZIP directly; GitHub's source archive is for building and development.

The development target is Minecraft Java 26.3, Iris 1.11.7 and Sodium 0.9.2.
Other versions, loaders and hardware combinations are not certified.

## Verification and limits

840 OpenGL graphics configurations and 818 controlled GPU regression cases pass,
including new palette, moon-occlusion, relief-direction and exact-work-skip checks.
The palette uses the existing LUT and lighting constants without extra passes or
lookups. The isolated foliage timing saving is small; full-game FPS and final
Minecraft appearance still need a live check.
