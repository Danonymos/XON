# XON Shader 1.0.7 — Smoother edges, softer light

This update brings built-in edge smoothing, a softer colored ore aura and more
readable, evolving cloud light to XON. It also includes the colored-light capture
repairs and cloud-shade redesign introduced during 1.0.6 development.

## Highlights

- **Smoother by default:** bounded spatial edge reconstruction, shared motion-blur
  coverage and gentler distant mip detail. No AA toggle or quality selector.
- **Softer ore light:** three extra open blocks ease the colored aura into darkness.
  The default setting reaches about seven blocks along open paths. Quartz casts violet spill.
- **A landscape in motion:** balanced light/shadow patches drift one block every
  two seconds, merging and separating through broad soft boundaries.
- **Readable moonlight:** exposed openings receive up to 28% more cool blue light.
- **Corrected terrain shadows:** remove reproduced camera-following self-shadow
  rings while preserving real cast/contact shadows.

## Also included since 1.0.3.3

- Better backlit building form, readable night/cave fill and restrained local lighting.
- Shadow-shaped underwater shafts, water-surface depth look-through, clearer
  nearby water and improved distant underwater background blending.
- Working colored-light capture and propagation in the Overworld, Nether and End,
  with source-texture preservation, wall blocking and violet quartz illumination.
- Balanced warped cloud shade replacing dark cellular spots and thin bright borders.

## Install

Download the **XON-Shader-v1.0.7.zip release asset**, leave it zipped and place it in
`shaderpacks`. Select it in Iris and Apply. Start with **Balanced + Native**.
GitHub's automatically generated source ZIPs are not installable shader packs.

Development target: Minecraft Java 26.3, Iris 1.11.7 and Sodium 0.9.2. Colored ore
lighting requires Iris custom-image/compute support; Speed disables that effect.

## Validation and limits

The shader source passed 840 OpenGL compile/link configurations and 790 controlled
GPU cases/comparisons. Isolated tests show lower AA edge/movement error, a faster
stationary final pass and similar moving-pass cost. These are synthetic RTX 5060 Ti
results, not a full-game FPS promise or certification of every hardware/mod stack.
Live Minecraft visual/FPS verification remains separate.

Voxel light follows open block paths inside a local volume. Spatial AA cannot
recover all missing subpixel information, and mip stabilization uses the game's
existing mip chain. See the repository's changelog and verification record for detail.
