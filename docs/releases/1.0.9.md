# XON Shader 1.0.9 — Balanced interiors, softer light

Indoor lamps now leave more room for shade: gentler peaks and a smooth midrange
falloff let neighboring pools of light blend into readable darker areas.

## Improved

- Balance the shared block-light path used by torches, lanterns, sea lanterns,
  end rods and other ordinary sources, along with held lights.
- Blend indoor and outdoor response continuously using each surface's skylight.
- Gently lower daytime sunlight, sky fill and daytime cave fill; retain moonlight
  and the night visibility floor. Reduce Nether and End ambient brightness.
- Keep the golden/teal palette, colored ore auras, moving cloud shade and built-in AA.
- Benchmark the candidate before adoption without adding passes, texture reads,
  buffers or CPU frame work. Actual GPU time is still hardware/scene dependent.

## Install

Place **XON-Shader-v1.0.9.zip** directly in your instance's `shaderpacks` folder,
then select it in Iris and Apply. Start with Balanced + Native.

The development target remains Minecraft Java 26.3, Iris 1.11.7 and Sodium 0.9.2.

## Verification and limits

840 graphics compile/link configurations and 842 controlled GPU regression cases
pass, including 24 new balance checks. The 1080p before/current benchmarks cover
lighting kernels and production terrain fragments, with interleaved GPU queries.
Live Minecraft appearance and full-game FPS still need checking.

Ordinary sources use Minecraft's scalar lightmap. This is an intensity/falloff
rebalance; it does not add directional source tracing or new lamp-cast shadows.
