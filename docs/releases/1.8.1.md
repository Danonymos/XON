# XON Shader 1.8.1 — A More Atmospheric End

The End gains a richer violet atmosphere to complement its galactic sky.

- **Lavender lighting:** islands and structures receive more character, with
  subtle color separation between exposed and shaded faces.
- **Violet-magenta haze:** soft, slowly drifting layers create depth around
  islands and through distant terrain, keeping nearby surfaces clear.
- **The same beautiful sky:** the galaxy, stars and black hole are preserved.
- **Efficient rendering:** the atmosphere fits into existing shading without
  extra render passes, texture lookups, ray marching or buffers.
- **The 1.8 improvements remain:** source-specific lamp lighting, cleaner
  indoor shadows and the performance optimizations are retained.

Start with **Balanced + Native**. Adjust **Atmosphere Density** and **Fog Density**
under **Sky & Atmosphere** to taste. Speed keeps the lighter atmosphere path.

Install **XON-Shader-v1.8.1.zip**. See the
[End atmosphere validation](https://github.com/Danonymos/XON/blob/main/docs/end-atmosphere-validation.md)
for testing scope and measurements.
