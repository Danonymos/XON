# XON Shader 1.2: Clear settings and richer colored light

- Focused settings pages use wide controls, concise labels and compact values.
  Hover for help and defaults; adjust sliders and buttons directly in Iris.
- Light Saturation defaults to 135% for colored light cast onto nearby blocks.
  Linear luminance and hue are preserved, with a safe limit for already saturated
  colors. Set it to 100% for the existing emitters' previous color response.
- Jack-o-lanterns cast a soft amber aura; soul lanterns cast cyan-teal light onto
  walls and floors. Their existing surface appearance is retained.
- Ordinary torch, regular-lantern and end-rod lighting retains its current balance.
  World grading, colored-light reach/falloff, occlusion and rendering budgets remain.

## Install

Place **XON-Shader-v1.2.zip** in the instance's `shaderpacks` folder, then select it
in Iris and Apply. Start with Balanced + Native. In **Colored Block Light**, use
**Colored Light** for cast auras and **Glowing Surfaces** for ore/plant surface glow.
Soul-lantern and jack-o-lantern auras require Colored Light, which Speed disables.

## Verification and limits

See the [verification record](../../VERIFICATION.md) for the checks performed.
The saturation target is a linear-light chroma gain, not a guarantee of 35% more
display saturation after tone mapping, texture modulation and surrounding light.
Already saturated source colors receive a smaller, hue-preserving gain.

The existing local voxel volume, compute dispatch and surface fetch count are
retained. Added emitter capture and arithmetic have a cost; no full-game FPS
guarantee is made. Auras follow open voxel paths and can shorten at walls,
corners or volume boundaries. Ordinary lamps still use scalar block-light data.
