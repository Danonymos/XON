# XON Shader 1.8.3 — Wall Light-Leak Fix, Quartz Pillar Falloff & Balanced Indoor Lighting

 Fixes local light leakage through 1-block walls and corners for both lamps and glowing ores, restores smooth floor-to-ceiling falloff on Quartz pillars, and rebalances indoor light intensity so shadows stay rich and readable while keeping all circular light radii intact.

- **Eliminate lamp and ore light leakage through walls and corners (`shadowcomp.csh`, `emissive_light.glsl`):**
  - Tightens 26-neighbor diagonal (`manhattan == 2`) and 3D corner (`manhattan == 3`) obstacle checks so air-to-air diagonal propagation requires both orthogonal intermediates open (`openA && openB`) and 3D corners require all six bounding face/edge intermediates open, while embedded emitters require a continuous face-connected open path.
  - Treats all solid blocks, glowing ore blocks (`2..9`), and solid decorative blocks (`134..136`: Amethyst, Sculk, and Quartz blocks/pillars/stairs/slabs) as opaque light-step obstacles (`xonBlocksLightStep`) and marks decorative solid blocks as occluded in `xonLightTex`, preventing Lanterns or Diamond Ores behind a wall from bleeding through to the front side.
  - Adds a sub-cube reachability mask (`oreOpen` / `lampOpen` vs `req`) in `xonSampleLocalLights` relative to the receiving front cell so trilinear interpolation on pillar sides, stairs, slabs, and wall corners never samples behind a 1-block wall (`0.0` leakage across flat walls, wall-ceiling corners, recessed alcoves, and Quartz pillar walls).
- **Fix Quartz pillar two-part brightness split (`shadowcomp.csh`):** weights decorative self-auras (`family 6..8, 21`) below active illumination sources in candidate selection (`bestScore`) so Quartz pillars (`block.10023`) lit by floor Sea Lanterns retain real lamp coverage across their full height and decay smoothly from bright at the floor to darker shade near the ceiling.
- **Rebalanced indoor light intensity (`lamp_light.glsl`, `lighting.glsl`, `geometry.fsh`):** lowers indoor lamp pool gain (`1.22 -> 0.94`), lamp shade fill (`0.85 -> 0.72`), indoor blocklight gain (`0.80 -> 0.68`), and indoor bounce/ambient caps while preserving every light source's radius, circular pool isotropy, and outdoor/End appearance.

Install **XON-Shader-v1.8.3.zip** and start with **Balanced + Native**. See [VERIFICATION.md](https://github.com/Danonymos/XON/blob/main/VERIFICATION.md) for GPU measurements and testing scope.
